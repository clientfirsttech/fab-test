It bites `--dry-run` and `local` against a large root that does contain artifacts. Cut from Empty Discovery Diagnostics on 2026-08-22 as off-centre for that epic; the fix is to route it through the shared pruning walker.

- [Playwright Render Diagnostics](tasks/archive/2026-08-30-playwright-render-diagnostics.md) — A render timeout or a broken visual used to report a bare "did not render within Xms" with no clue why: the embed SDK's `report.on('error', ...)` never sees a per-visual failure (that event dispatches on `document.body`, not the report object), and even a report-level failure that legitimately fires `error` could still get silently clobbered back to `rendered` if the two events landed within ~60ms of each other.
